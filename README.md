# Overview

This is a small "Hello World" program I wrote to set up and verify my full development workflow  writing code, running it locally, and publishing it to a public GitHub repository so I have a clean, repeatable process for the larger projects that follow.

The software is a short Node.js script. It prints "Hello World" to the terminal and then prints a brief personalized greeting that includes the current date and time, which confirms the script actually executed.

My purpose for building it was to confirm that my toolchain (Node.js, Git, and VS Code) works end to end and to practice the complete cycle of creating software and sharing it publicly.

# Development Environment

* Visual Studio Code as the code editor, using its integrated terminal to run the program
* Node.js as the JavaScript runtime
* Git and GitHub for version control and public publishing

The program is written in **JavaScript**, executed with **Node.js**. It uses only the built-in `Date` object and `console.log`, so it runs with no external packages.
